# Solitaire
My family has always loved card games, and we all enjoyed Solitaire at some point. I like Balatro and wanted to learn
the Love2d framework, so here we are. Nothing fancy, just normal Solitaire!

<img width="1020" height="573" alt="solitaire" src="https://github.com/user-attachments/assets/d99434e2-bac0-4ed8-a4d5-5835a0d8d34d" />

## Features
The app features neat object-oriented and functional programming "addons", or functions that I made to get around the simplistic nature of the Lua programming language. I also created my own pixel art for the cards! 

## To Play
To play, make sure you install [Love2d](https://love2d.org/). Then, you can clone the repo, and run `love .` in the root directory of the repo.
